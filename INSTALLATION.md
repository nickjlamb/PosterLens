# Installation Guide

This guide provides step-by-step instructions for setting up and running the PosterLens app on your iOS device or simulator.

## Prerequisites

Before you begin, ensure you have the following:

- Xcode 15.0 or later
- iOS 16.0 or later device or simulator
- Perplexity API key (sign up at [perplexity.ai](https://www.perplexity.ai) )
- Git installed on your machine
